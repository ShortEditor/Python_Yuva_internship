# Week 3 — Unsupervised Learning and Clustering Analysis
Dataset: Iris, publicly available and distributed by scikit-learn.

Methods: StandardScaler, K-Means, elbow method, silhouette score, PCA, and Ward hierarchical clustering.

K=3 is the final segmentation choice based on the elbow/interpretability trade-off. The report transparently notes that silhouette score alone favors K=2. Species labels are not used during clustering and are used only for post-hoc interpretation.
