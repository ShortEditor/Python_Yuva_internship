This Week 3 project applies unsupervised learning to the publicly available Iris dataset using Python and Scikit-learn. The objective was to discover meaningful groups without using the known species labels during model training. The workflow includes feature selection, standardization, K-Means clustering, elbow analysis, silhouette evaluation, PCA visualization, cluster profiling, and hierarchical clustering.

Candidate values of K from 2 to 6 were evaluated using inertia and silhouette score. The silhouette metric favored K=2, while the elbow curve and practical interpretability supported a three-group segmentation, so K=3 was selected with this trade-off explicitly documented. The final clusters were visualized using PCA and petal measurements and were profiled using original-scale feature means.

Known Iris species labels were intentionally excluded from clustering and were used only after fitting to interpret how the discovered groups correspond to an external classification. Hierarchical Ward clustering was also used as a secondary comparison. The report discusses K-Means assumptions, feature scaling, model-selection ambiguity, PCA limitations, arbitrary cluster labels, and the distinction between unsupervised clustering and supervised classification. The project includes the Word report, reproducible Python script, clustered dataset, selection metrics, and visualization files.
