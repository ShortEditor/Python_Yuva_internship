This Week 4 project implements a supervised binary classification model using the publicly available Breast Cancer Wisconsin (Diagnostic) dataset and Scikit-learn. The objective is to classify observations as malignant or benign using 30 numerical diagnostic features. Logistic Regression was selected as an interpretable and efficient baseline model.

The project follows a leakage-safe machine-learning workflow. The data is divided into stratified training and held-out test sets before model fitting. StandardScaler and Logistic Regression are combined in a Scikit-learn Pipeline so preprocessing parameters are learned only from training data. Five-fold stratified cross-validation is used to evaluate consistency, and GridSearchCV tunes the regularization parameter C using ROC-AUC.

Performance is evaluated using accuracy, precision, recall, F1 score, and ROC-AUC. A confusion matrix and ROC curve provide additional insight into classification behavior, while permutation importance is used to examine influential features. The report discusses model rationale, preprocessing, validation, hyperparameter tuning, error analysis, strengths, limitations, and possible improvements. The benchmark results are interpreted cautiously because the dataset is not evidence of clinical deployment. Reproducible code, dataset output, predictions, and visualizations are included.
