# Week 4 — Supervised Learning Model Implementation
Problem: Binary classification of malignant vs benign observations.
Dataset: Breast Cancer Wisconsin (Diagnostic), distributed by scikit-learn.
Methods: train/test split, StandardScaler + Logistic Regression Pipeline, 5-fold StratifiedKFold, GridSearchCV, Accuracy, Precision, Recall, F1, ROC-AUC, confusion matrix, ROC curve, permutation importance.
