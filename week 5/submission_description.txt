This Week 5 project applies deep learning to handwritten digit classification using the publicly available scikit-learn Digits dataset and PyTorch. A compact Convolutional Neural Network (CNN) was designed to exploit the spatial structure of 8×8 grayscale images. The workflow covers data normalization, stratified train/validation/test splitting, CNN architecture design, ReLU activations, max pooling, dropout regularization, Adam optimization, validation monitoring, early stopping, and held-out test evaluation. Performance was assessed using accuracy, weighted precision, weighted recall, weighted F1 score, test loss, a confusion matrix, per-class F1 scores, and example predictions. The report includes a network architecture diagram, training curves, evaluation results, design justifications, practical challenges such as overfitting and small image resolution, and critical analysis of strengths, limitations, and possible improvements.
