This Week 6 capstone presents a complete end-to-end data science pipeline using the publicly available Titanic passenger dataset. The project integrates data acquisition, cleaning, feature engineering, exploratory data analysis, supervised learning, unsupervised learning, evaluation, interpretation, and recommendations. A Random Forest classifier was trained to predict survival using demographic, travel, and engineered family features. Stratified train-test splitting and five-fold cross-validation were used for rigorous evaluation, with the held-out test set achieving 81.6% accuracy, 77.2% F1, and 0.858 ROC-AUC. K-Means clustering was also applied to standardized passenger characteristics to discover descriptive passenger segments, with k=2 selected using silhouette analysis. The report includes Python code examples, EDA visualizations, confusion matrix and feature importance analysis, cluster evaluation and PCA visualization, challenges, limitations, recommendations, and future work.
