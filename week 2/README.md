# Week 2 — Exploratory Data Analysis and Visualization

This project performs exploratory data analysis on the cleaned Titanic passenger dataset produced during Week 1.

## Files
- `Week2_EDA_Visualization_Report.docx` — complete internship report
- `eda_titanic.py` — reproducible Python EDA script
- `titanic_cleaned.csv` — dataset used for analysis
- `figures/` — report-ready EDA charts

## Main findings
- Overall survival rate: 38.4%
- Female survival rate: 74.2%
- Male survival rate: 18.9%
- First-class survival rate: 63.0%
- Third-class survival rate: 24.2%

The analysis includes descriptive statistics, grouped aggregations, distribution analysis, multivariate subgroup analysis, family-size analysis, port analysis, fare analysis, and a correlation matrix. All interpretations are framed as associations rather than causal claims.
